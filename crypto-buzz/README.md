# 暗号資産 話題チェック

ダブルクリックすると、いま話題の暗号資産とニュースをまとめたページがブラウザで開く、自分用のツールです。
どの項目からも元の記事や X の投稿へ移動できます。

## 表示される内容

| 欄 | データ元 | 元の情報へのリンク |
|---|---|---|
| いま話題の銘柄（15件） | CoinGecko のトレンド（検索が急増している順） | X のリアルタイム検索（`$記号`・日本語）、CoinGecko の銘柄ページ |
| 関連ニュース | 下のニュースの見出しに、その銘柄名や記号が含まれるもの | 記事本文 |
| 話題のカテゴリ | CoinGecko | CoinGecko のカテゴリページ |
| 最新ニュース | CoinPost / CoinDesk / Cointelegraph / Decrypt の RSS | 記事本文 |
| Reddit で盛り上がっている投稿 | r/CryptoCurrency の人気投稿 | Reddit の投稿 |

X(Twitter) の投稿は API が有料なので、自動では取得しません。かわりに、銘柄ごとに X の検索結果（最新順）を開くリンクを付けています。

## 準備（最初の1回だけ）

1. **Python 3** を入れておきます（3.8 以上。追加のライブラリは不要です）。
   - Windows: https://www.python.org/downloads/ からインストールします。
   - Mac: ターミナルで `python3 --version` と入力し、バージョンが表示されれば入っています。
2. この `crypto-buzz` フォルダを、PC の好きな場所に置きます。

## デスクトップにショートカットを作る

### Windows
1. `open_buzz.bat` を右クリックし、「その他のオプションを確認」→「送る」→「デスクトップ（ショートカットを作成）」を選びます。
2. 名前は「話題チェック」などに変えて構いません。

### Mac
1. 最初の1回だけ、ターミナルで次を実行します（ダブルクリックで実行できるようにする設定です）。
   ```
   chmod +x /置いた場所/crypto-buzz/open_buzz.command
   ```
2. `open_buzz.command` を右クリックし、「エイリアスを作成」を選びます。できたエイリアスをデスクトップに移動します。
3. 初回にセキュリティの警告が出た場合は、右クリックから「開く」を選びます。

ダブルクリックするたびに最新のデータを取り直し、ブラウザで開きます。

## 補足

- 生成されたページは `output/buzz.html` に保存されます。
- 取得できなかったデータ元があると、ページ上部に赤い文字で表示されます。ほかのデータ元はそのまま表示されます。
- ニュースのデータ元は、`buzz.py` の `NEWS_FEEDS` に RSS の URL を追加すると増やせます。
- 表示されるのは情報だけです。売買の判断はご自身で行ってください。
