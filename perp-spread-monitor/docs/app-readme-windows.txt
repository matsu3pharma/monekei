Perp DEX 乖離モニター（Windows 版）
====================================

■ 起動のしかた
1. この「PerpSpreadMonitor」フォルダを、ドキュメントなど好きな場所に置きます
   （ダウンロードフォルダの zip の中のままでは起動しないでください。先に「すべて展開」してください）
2. PerpSpreadMonitor.exe をダブルクリックします
3. 初回だけ、デスクトップに「Perp DEX 乖離モニター」のショートカットが作られます。
   次からはデスクトップのアイコンをダブルクリックするだけで起動します

※ 初回に「Windows によって PC が保護されました」と出たら、
  「詳細情報」→「実行」を押してください（個人で作ったアプリで、電子署名が無いため表示されます）

■ 画面
起動すると専用のウィンドウ（Edge または Chrome）で一覧が開きます。
ウィンドウを閉じてもモニターは裏で動き続け、通知も届きます。
もう一度アイコンをダブルクリックすると、画面だけ開き直します。

■ 止めるとき
画面右上の「終了」ボタンを押します。

■ 設定（通知先・しきい値など）
画面右上の「設定を開く」を押すと、メモ帳で設定ファイル（config.json）が開きます。
保存すると30秒以内に反映されます（再起動は不要）。
設定ファイルとログ（monitor.log）は、この exe と同じフォルダに作られます。

※ config.json には Discord の Webhook URL などが入るので、人に渡さないでください。
